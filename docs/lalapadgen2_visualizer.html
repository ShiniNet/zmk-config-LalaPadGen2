LaLapad Gen2 大西配列キーマップ

config/lalapadgen2.keymap から生成。実機のカラムスタッガード（列ごとの縦ずれ）で表示。文字は JIS 入力として表示（小さい字は ZMK のキー名）。接続先が Windows（Bluetooth プロファイル 4・5、USB）のときの割当は「Windows」に切り替えて見る。紫の枠＝Mac と割当が違うキー。

変更（最終版、2026-11-26）: ① BT 切り替えは かな長押し（L4 Mouse）へ移した。右手の上段に左から BT 1〜5、その下の段に出力先切替・再起動・書込モード・BT 登録解除・BT 全解除。System（L8）には F キーとトラックパッドの速さだけを残した。② .vil の L5（QWERTY）と L6（別のカナ配列）を削除し、後ろのレイヤーを繰り上げた（空きの L7〜L9 → L5〜L7、System は L10 → L8）。③ Num の右下段は Esc をやめて、その位置に ／、隣に −。④ 右下段の Delete・戻る の仮置きをやめた。⑤ コンボの待ち時間を 10000 ms → 50 ms に短くした。⑥ USB でつないでいるあいだは Windows の割当にした（REQ-195 追記4。Bluetooth は 4・5 が Windows、1〜3 と未接続は Mac のまま）。⑦ ？ のキーはシフトを保持したまま押しても ！ になる（mod-morph、REQ-195 追記5。コンボは同時押しのときだけだった）。⑧ トラックパッドの速さ: 右はカーソルを速く（1/5 → 1/4）、スクロールを遅く（1/12 → 1/18）。左は低速に（カーソル 1/12、スクロール 1/60）。低速モードも連動。

同時押し（コンボ）

Cornix_20261126.vil の定義どおり（Shift の親指と ? をほぼ同時に押すと !）。Base でだけ働く。待ち時間は 50 ms（ZMK・Vial の標準値。.vil の 10000 ms から短くした）。2 つ目のキーが 50 ms 以内に来ないときは、それぞれ普通に押したことになる。

トラックパッドの操作

Mac 表示は macOS のトラックパッドの作法、Windows 表示は Windows の相当操作（仮想デスクトップ・タスクビューなど）。1本指で移動、2本指でスクロール（慣性あり）、カーソルの慣性はなし。薄い字は下のレイヤーから引き継いだ割当。
