## 2. レイヤーの対応

| 番号 | 名前 | .vil の中身 | 出し方 | Gen2 での扱い |
| --- | --- | --- | --- | --- |
| 0 | Base | 大西配列 | 常時 | .vil どおり |
| 1 | Num | 数字・記号・テンキー | Enter 長押し | .vil どおり。トラックパッドは低速モードになる（Gen2 標準の shield 設定が layer 1・2 に掛かる） |
| 2 | Nav | 矢印・ページ移動・編集 | BS 長押し | .vil どおり。同上の低速モード |
| 3 | Fn | F1〜F12 | 英数 長押し | .vil どおり |
| 4 | Mouse | マウス移動・ホイール・クリック | かな 長押し | .vil どおり（ACL0 を除く） |
| 5〜9 | L5〜L9 | すべて KC_NO（エンコーダーだけ割当あり） | 出すキーなし | 空きレイヤーとして残した。5方向スイッチにエンコーダーの割当を写した |
| 10 | System（追加） | なし | Num と Nav を同時に出す（Enter と BS を両方長押し） | Gen2 標準の System レイヤーをそのまま移した。BT 0〜3 の切替・登録解除、USB/BT 切替、再起動、書込モード、トラックパッドの速度調整、F1〜F15 |

Cornix では Enter と BS を両方長押しすると Nav（L2）になっていた。Gen2 では System（L10）になる。

## 3. 置き換えた点（Gen2 に同じキーがないもの）

| .vil の割当 | 場所（.vil） | Gen2 での置き場所 | 理由 |
| --- | --- | --- | --- |
| Esc | 左外側・上段（L0〜L2・L4） | 左小指 Q＋E の同時押し（位置 0+10） | Gen2 は片手5列。外側の列の上段を「上段＋中段」に置いた |
| Tab | 左外側・中段（L0〜L2・L4） | 左小指 E＋J（10+20） | 外側の列の中段を「中段＋下段」に置いた |
| 戻る（KC_WBAK） | 右外側・上段（L0〜L3） | 右小指 P＋H（9+19） | 同上 |
| 右Shift（KC_RSHIFT） | 右外側・上段（L4 だけ） | 右小指 P＋H（9+19、L4 だけ） | 同上 |
| Delete | 右外側・中段（L0〜L4） | 右小指 H＋B（19+29） | 同上 |
| USER00〜02 | 左外側（L3 だけ） | 置いていない | Cornix 固有のキー。Bluetooth の接続先切替なら Gen2 では System の BT 0〜2 で代わりになる |
| 左エンコーダー回転 輝度−/輝度＋（L0〜L4）、音量−/音量＋（L5〜L9） | 左エンコーダー | 左5方向スイッチの 下/上 | エンコーダーがないため |
| 右エンコーダー回転 音量−/音量＋（L0〜L4）、ホイール↑/↓（L5〜L9） | 右エンコーダー | 右5方向スイッチの 下/上 | 同上 |
| Sleep（L0〜L4）、ミュート（L5〜L9） | 左の列6 | 左5方向スイッチの押し込み | 同上 |
| ミュート（L0〜L4）、中クリック（L5〜L9） | 右の列6 | 右5方向スイッチの押し込み | 同上 |
| （割当なし） | — | 5方向スイッチの左・右 | 空き（6章の確認事項） |
| KC_ACL0（マウス低速） | L4 J・B の位置 | なし（&none） | ZMK にマウスキーの加速度切替がない |
| KC_SLEP（Generic Desktop の System Sleep） | 左の列6 | Consumer の Sleep（C_SLEEP） | ZMK は Generic Desktop のシステム操作を送らないため、Consumer ページで送る |
| RSFT_T(KC_NO) | 右親指（L0） | 右Shift（&kp RSHIFT） | タップで何も出さないので、ただの Shift と同じ |
| tap_dance・combo・macro | — | — | .vil では全部未使用（中身はすべて KC_NO） |

キーコードはすべて同じ HID の値で送る（例: KC_RBRACKET→RBKT、KC_NONUS_HASH→NON_US_HASH、KC_UNDO→K_UNDO、KC_WBAK→C_AC_BACK）。Mac が JIS として認識していれば、Cornix と同じ文字が出る。

## 4. Gen2 標準ファームウェアから外したもの・残したもの

- 外した: QWERTY のベース層、Gen2 標準のコンボ（Q+W=Esc・A+S=Tab の横並び）、5方向スイッチの矢印、`=`/`-` の mod-tap（mt2）、タップダンス（td_mo12）、Num・Symbol 層の中身
- 残した: トラックパッドの仮想キー（52〜67）の割当、Num レイヤーでの ⌃⌘←/⌃⌘→（Gen2 標準の L1 の設定）、System レイヤー、Num+Nav→System の条件付きレイヤー、shield 側の設定（低速モード・速度調整・LED・充電表示）はすべて変更なし。`.conf`・shield・`build.yaml` は触っていない

## 5. タップホールドの設定

.vil の設定（QMK Settings）: Tapping Term 250 ms、Permissive Hold オン、Hold On Other Key Press オフ、Chordal Hold オン、Flow Tap 120 ms、Combo の待ち時間 50 ms。

| .vil | ZMK |
| --- | --- |
| Tapping Term 250 | tapping-term-ms 250 |
| Permissive Hold | flavor "balanced" |
| Flow Tap 120 | require-prior-idle-ms 120（直前のキーから 120 ms 以内ならタップ扱い） |
| Quick Tap Term（未設定＝Tapping Term） | quick-tap-ms 250 |
| Chordal Hold | Shift 付き Space（mod-tap）だけ、反対の手のキーか親指キーと重なったときにホールドにする（hold-trigger-key-positions、判定はキーを離したとき）。レイヤータップ（英数・Enter・BS・かな）には掛けていない |
| Combo 50 ms | 各コンボの timeout-ms 50 |

Chordal Hold をレイヤータップにも掛けると、Enter 長押しで左手の数字を速く打ったときに Enter が出てしまう。Cornix 側で親指キーがどちらの手として扱われていたかは .vil から読めないので、上の形にした。

## 6. 確認してほしいこと（仮に決めて入れてある）

1. **外側の列（Esc・Tab・戻る・Delete）の置き場所**
   - A（今の設定）: 小指の縦2キー同時押し。同じ指で縦に押すので、普段の打鍵で誤って出にくい
   - B: 5方向スイッチの空いている左右に置く（例: 左スイッチの左＝Esc・右＝Tab、右スイッチの左＝戻る・右＝Delete）
   - C: Gen2 標準と同じ横並びの同時押し（Q+L＝Esc、E+I＝Tab）。大西配列では「ei」が頻出するので誤爆しやすい
2. **トラックパッドのジェスチャー**（Gen2 標準は Windows 向け: ←/→＝マウスボタン4/5、↑＝⌘Tab、↓＝⌘D、ピンチ＝Ctrl、Num 層の ←/→＝⌃⌘←/⌃⌘→）
   - A（今の設定）: Gen2 標準のまま
   - B: Mac 向けに変える（例: ←/→＝⌃←/⌃→ でデスクトップ切替、↑＝⌃↑ Mission Control、↓＝⌃↓ アプリ Exposé、ピンチ＝⌘）
3. **5方向スイッチの押し込みの Sleep**（左）: Cornix の割当どおり入れたが、押し込みは誤って押しやすく、押すと Mac がスリープする
   - A（今の設定）: そのまま
   - B: 外す（&none）
   - C: System レイヤーに移す
4. **Undo・Cut・Copy・Paste・Again と「戻る」**（HID の専用キー）: .vil どおり送っているが、Mac のアプリの多くはこれらに反応しない（Cornix 用の Karabiner 設定では ⌘Z などに置き換えていた）
   - A（今の設定）: .vil どおり
   - B: Mac のショートカットにする（Undo＝⌘Z、Cut＝⌘X、Copy＝⌘C、Paste＝⌘V、Again＝⇧⌘Z、戻る＝⌘[）
5. **5方向スイッチの空いている左右**（コンボを A のままにする場合）
   - A（今の設定）: 空き
   - B: Gen2 標準どおり矢印 ←/→
   - C: 前の曲/次の曲など
6. **Cornix の USER00〜02**（L3 の左外側）が何だったか。Bluetooth の接続先切替なら System の BT 0〜2 で足りる。別の機能なら置き場所を決める
