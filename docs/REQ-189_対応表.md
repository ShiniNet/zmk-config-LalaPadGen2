## REQ-193 で直したこと（2026-11-26 稜太の指示）

- 左下段の修飾キー: Ctrl と ⌘ を入れ替えた（位置 30＝⌘、31＝Opt、32＝Ctrl）
- 右下段に修飾キーは置かない。右Ctrl の跡（41）に Esc。右⌘・右Opt の跡（39・40）に Delete と 戻る を仮置き（Num レイヤーだけは .vil どおり : と /）
- 右親指の Shift（37）: タップ＝Tab、長押し＝Shift（Base レイヤー。Num〜Mouse レイヤーは .vil どおりタップ＝Space、Fn は App）
- 5方向スイッチの左右: 左手＝← →、右手＝左がコピー（⌘C）・右がペースト（⌘V）。押し込み・上下は変更なし（Sleep は「そのまま」で確定）
- Num レイヤーのテンキーを右へ1列ずらした（下の表）

| 位置 | 前 | 今 |
| --- | --- | --- |
| 5・6・7・8・9（右上段） | 7・8・9・＋・− | ＋・7・8・9・− |
| 15・16・17・18・19（右中段） | 4・5・6・＊・／ | ：・4・5・6・／ |
| 25・26・27・28・29（右下段） | 1・2・3・0・． | 0・1・2・3・． |

数字はすべてテンキーのキー（KP）。「：」は JIS の : のキー（Num レイヤー左手の : と同じ）。テンキーの ＊ は外した。JIS では ⇧＋: で ＊ が出る（＋ も ⇧＋; で出る）。

## REQ-192 で直したこと（2026-11-25 稜太の指示）

1. ビジュアライザーを実機のカラムスタッガード（列ごとの縦ずれ）で表示するようにした。親指キー・5方向スイッチ・トラックパッドの位置も実機に合わせた
2. トラックパッドの操作を macOS のトラックパッドの作法に合わせた（5章）
3. .vil にない同時押し（REQ-189 で仮に置いた小指の縦2キー同時押し）を撤去した。Cornix の外側の列は 5方向スイッチの左右に置いた（3章）

## 2. レイヤーの対応

| 番号 | 名前 | .vil の中身 | 出し方 | Gen2 での扱い |
| --- | --- | --- | --- | --- |
| 0 | Base | 大西配列 | 常時 | .vil どおり |
| 1 | Num | 数字・記号・テンキー | Enter 長押し | .vil どおり。トラックパッドは低速モードになる（Gen2 標準の shield 設定が layer 1・2 に掛かる） |
| 2 | Nav | 矢印・ページ移動・編集 | BS 長押し | .vil どおり。同上の低速モード |
| 3 | Fn | F1〜F12 | 英数 長押し | .vil どおり |
| 4 | Mouse | マウス移動・ホイール・クリック | かな 長押し | .vil どおり（ACL0 を除く） |
| 5〜9 | L5〜L9 | すべて KC_NO（エンコーダーだけ割当あり） | 出すキーなし | 空きレイヤーとして残した。5方向スイッチにエンコーダーの割当を写した |

Cornix では Enter と BS を両方長押しすると Nav（L2）になっていた。Gen2 では System（L10）になる。

## 3. 置き換えた点（Gen2 に同じキーがないもの）

5方向スイッチは「上下＝エンコーダーの回転」「押し込み＝エンコーダーの押下キー」「左右＝左手は ← →、右手はコピー・ペースト（REQ-193）」とした。

| .vil の割当 | 場所（.vil） | Gen2 での置き場所 |
| --- | --- | --- |
| Esc | 左外側・上段（L0〜L2・L4） | 右下段の小指（位置 41、L0〜L4 共通） |
| Tab | 左外側・中段（L0〜L2・L4） | 右親指の Shift のタップ（位置 37、Base レイヤー） |
| 戻る（KC_WBAK） | 右外側・上段（L0〜L3） | 右下段の薬指（位置 40、Num 以外の L0〜L4。仮置き） |
| 右Shift（KC_RSHIFT） | 右外側・上段（L4 だけ） | 置いていない（L4 でも右親指の 37 が Shift） |
| Delete | 右外側・中段（L0〜L4） | 右下段の中指（位置 39、Num 以外の L0〜L4。仮置き） |
| USER00・USER01 | 左外側・上段/中段（L3 だけ） | 置いていない。USER02（下段）も同様 |
| 右⌘・右Opt・右Ctrl | 右親指行 | 置いていない（REQ-193。修飾キーは左下段だけ） |
| 左エンコーダー回転 輝度−/輝度＋（L0〜L4）、音量−/音量＋（L5〜L9） | 左エンコーダー | 左5方向スイッチの 下/上（44/46） |
| 右エンコーダー回転 音量−/音量＋（L0〜L4）、ホイール↑/↓（L5〜L9） | 右エンコーダー | 右5方向スイッチの 下/上（49/47） |
| Sleep（L0〜L4）、ミュート（L5〜L9） | 左の列6 | 左5方向スイッチの押し込み（42） |
| ミュート（L0〜L4）、中クリック（L5〜L9） | 右の列6 | 右5方向スイッチの押し込み（51） |

## 4. Gen2 標準ファームウェアから外したもの・残したもの

- 外した: QWERTY のベース層、Gen2 標準の同時押し（Q+W=Esc・A+S=Tab）、5方向スイッチの矢印、`=`/`-` の mod-tap（mt2）、タップダンス（td_mo12）、Windows 向けのトラックパッド割当
- 残した: System レイヤー、Num+Nav→System の条件付きレイヤー、トラックパッドの低速モード・速度調整、LED・充電表示。`build.yaml`・`lalapadgen2.conf` は触っていない
- 変えた shield 設定: `lalapadgen2_left.conf`・`lalapadgen2_right.conf` のトラックパッド設定 3 項目（5章）

## 5. トラックパッド（macOS の作法に合わせた割当）

左右のパッドで同じ割当。全レイヤー共通（Gen2 標準にあった Num レイヤーだけの割当 ⌃⌘←/⌃⌘→ は外した）。

| 操作 | Gen2 標準（Windows 向け） | 今の割当 | Mac のトラックパッドでの同じ操作 |
| --- | --- | --- | --- |
| 1本指で移動 | カーソル移動（指を離した後も慣性で滑る） | カーソル移動（慣性なし） | カーソル移動（慣性なし） |
| 2本指で上下左右 | スクロール（慣性あり） | 変更なし | スクロール（慣性あり）。向き（ナチュラル）は Mac の設定で決まる |
| 1本指でタップ（MB1） | 左クリック | 変更なし | タップでクリック |
| 1本指でタップして、すぐ触れたまま動かす | ドラッグ | 変更なし | 「ドラッグにトラックパッドを使用」のダブルタップドラッグ |
| 2本指でタップ（MB2） | 右クリック | 変更なし | 副ボタンのクリック |
| 3本指でタップ（MB3） | 中クリック | 調べる（⌃⌘D） | 「調べる＆データ検出: 3本指でタップ」 |
| 2本指・3本指のタップドラッグ | 右・中ボタンを押したまま | 切った | （Mac にはない） |
| 3本指で右へスワイプ（MB4） | 戻る | ⌃←（左の操作スペースへ） | 3本指で右へスワイプ＝フルスクリーンアプリ間のスワイプ |
| 3本指で左へスワイプ（MB5） | 進む | ⌃→（右の操作スペースへ） | 同上 |
| 3本指で上へスワイプ（MB6） | Win+Tab | ⌃↑（Mission Control） | 3本指で上へスワイプ |
| 3本指で下へスワイプ（MB7） | Win+D | ⌃↓（アプリケーションウインドウ） | 3本指で下へスワイプ（App Exposé） |
| 2本指でピンチ（ZMOD） | Ctrl＋ホイール | ⌘＋ホイール | ピンチで拡大・縮小 |

- スワイプの向きと MB4〜7 の対応は、ドライバー（zmk-driver-iqs9151 v1.0.0）の実装（右→MB4、左→MB5、上→MB6、下→MB7）と Gen2 の説明書（HowtoUse）の既定割当表で確かめた。説明書の Num レイヤーの表だけは左右が逆に書かれているので、実機での確認が要る
- ⌃←・⌃→・⌃↑・⌃↓ は macOS のキーボードショートカット（Mission Control）の既定値。システム設定で切っていると効かない
- 2本指の左右スワイプでのブラウザの戻る・進む（Mac の「ページ間をスワイプ」）は、ファームウェアからは横スクロールとしてしか送れないため再現できない

## 6. タップホールドの設定

.vil の設定（QMK Settings）: Tapping Term 250 ms、Permissive Hold オン、Hold On Other Key Press オフ、Chordal Hold オン、Flow Tap 120 ms、Combo の待ち時間 50 ms（同時押しは未使用）。

| .vil | ZMK |
| --- | --- |
| Tapping Term 250 | tapping-term-ms 250 |
| Permissive Hold | flavor "balanced" |
| Flow Tap 120 | require-prior-idle-ms 120（直前のキーから 120 ms 以内ならタップ扱い） |
| Quick Tap Term（未設定＝Tapping Term） | quick-tap-ms 250 |
| Chordal Hold | Shift 付き Space（mod-tap）だけ、反対の手のキーか親指キーと重なったときにホールドにする（hold-trigger-key-positions、判定はキーを離したとき）。レイヤータップ（英数・Enter・BS・かな）には掛けていない |

Chordal Hold をレイヤータップにも掛けると、Enter 長押しで左手の数字を速く打ったときに Enter が出てしまう。Cornix 側で親指キーがどちらの手として扱われていたかは .vil から読めないので、上の形にした。

## 7. 判断してほしいこと（仮の設定で入れてある）

REQ-189 の「5方向スイッチの押し込みの Sleep」は REQ-193 で「そのまま」に決まった。

残っているもの:

- **(b) Undo・Cut・Copy・Paste・Again と「戻る」**（HID の専用キー）: .vil どおり送っているが、Mac のアプリの多くはこれらに反応しない。A（今の設定）.vil どおり／B Mac のショートカットにする（Undo＝⌘Z、Cut＝⌘X、Copy＝⌘C、Paste＝⌘V、Again＝⇧⌘Z、戻る＝⌘[）
- **(c) Cornix の USER00〜02**（L3 の左外側）が何の機能だったか。Bluetooth の接続先切替なら System の BT 0〜2 で足りる
- **(d) ピンチ中の修飾キー**: Gen2 の作者が Mac 向けに挙げている ⌘ にした。ブラウザのページの拡大・縮小は ⌘＋ホイールでは効かないアプリが多い。A（今の設定）⌘／B ⌃（Gen2 標準と同じ。macOS の「スクロールジェスチャで拡大縮小」をオンにすると画面全体が拡大する）

REQ-193 で仮に決めたもの:

- **(e) Delete と 戻る の置き場所**: 右下段の中指（39）＝Delete、薬指（40）＝戻る にした。Num レイヤーでは .vil どおり : と / のままなので、Num レイヤーでは Delete・戻るは押せない
- **(f) 右親指の Shift のタップ**: Base だけ Tab にした。Num・Nav・Mouse レイヤーは .vil どおり Space、Fn は App のまま。全レイヤーで Tab にすることもできる
- **(g) Num レイヤーのテンキーの演算子**: 右上の外側に ＋ を残し、＊ を外した（⇧＋: で出る）。− と ／ と ． は元の位置
- **(h) L4（Mouse）の右Shift**: Cornix では外側の列にあったが、置き場がないので外した（右親指の 37 で Shift は使える）
